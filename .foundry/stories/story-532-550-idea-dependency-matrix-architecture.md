# Create Idea Dependency Matrix Architecture

## Summary
Design and implement the initial structure and scripts for maintaining a lightweight historical mapping metadata index of Idea dependencies.

## Requirements
- Define the schema and format for `.foundry/docs/architecture/idea_dependency_matrix.md`.
- Implement a script or process to populate and update this matrix from existing Foundry nodes.
