# Story: Multi-Box Text Search Engine

## Context
As part of the Multi-Box Search Engine epic, we need to implement the core search functionality. This will allow users to search for specific Pokémon across all boxes using text-based queries.

## Objectives
- Implement a global text search input.
- Filter Pokémon across all boxes by matching the input against Pokémon Nickname, Species Name, and OT Name.
- Update the UI to reflect the search results efficiently.
