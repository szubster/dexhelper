# Rematch Trainer Card Component

## Overview
Design and implement the individual trainer cards or rows that will be displayed in the Rematch Dashboard. The component must display tier (1-5) information, team summaries, and EV totals.

## Objectives
- Implement a reusable trainer card/row component.
- Display current trainer tier correctly.
- Display accurate team summaries and specific EV totals per trainer.
- Apply tactical design system styling (`rounded-none`, `border-dashed`, `font-mono`).

## Acceptance Criteria
- [ ] Create trainer card/row component.
- [ ] Display tier and team EV totals accurately.
- [ ] Comply with ADR 008 aesthetic guidelines.
