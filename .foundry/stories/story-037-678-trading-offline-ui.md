# Story: Trading Offline UI

## Context
To facilitate trading between the user's concurrent saves, an offline-first user interface is required. This UI should allow users to select their save files, view Pokémon, and initiate trades.

## Requirements
- Build a user interface allowing side-by-side view of two selected save files.
- Enable users to initiate a transfer, providing visual feedback of the validation checks.
- Adhere to the strict Tactical UI aesthetic guidelines (ADR 008).
