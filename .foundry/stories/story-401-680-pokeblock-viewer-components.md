# Gen 3 Pokéblock UI Components

## Context
As part of `epic-114-401-gen3-pokeblock-dashboard-ui-retry`, we need to implement the specific UI components to display Pokéblock data, strictly adhering to ADR 008 (tactical hardware aesthetic).

## Acceptance Criteria
- [ ] Implement a list/grid view to display all Pokéblocks in the inventory.
- [ ] Implement a detailed view/card for each Pokéblock showing exact levels for Cool, Beauty, Cute, Smart, Tough, and Feel.
- [ ] Style the components using tactical hardware aesthetics (`rounded-none`, `border-dashed`, monospaced fonts, etc.).
