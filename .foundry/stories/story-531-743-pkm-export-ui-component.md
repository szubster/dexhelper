# Story: PKM/PK3 Export UI Component Integration

## Overview
This story focuses on implementing the user interface for exporting Pokémon data into `.pkm` or `.pk3` files.

## Objectives
- Implement an "Export" action button in the individual Pokémon detail view within the Party view.
- Implement an "Export" action button in the individual Pokémon detail view within the PC Box view.
- Wire the button to the data extraction logic, triggering a file download with the appropriate extension (`.pkm` or `.pk3`).
