# Story: Define Tactical Form Utilities

## Objective
Implement custom form and interaction utilities (`tactical-button`, `tactical-input`, `tactical-focus`) in `src/index.css` using Tailwind v4's `@utility` directive, in accordance with ADR 024.

## Scope
1. Define the `@utility tactical-button` primitive in `src/index.css` incorporating interactive states (hover/active).
2. Define the `@utility tactical-input` primitive for form elements.
3. Define the `@utility tactical-focus` primitive to standardize focus ring styling.

## Acceptance Criteria
- [ ] `tactical-button` utility is defined.
- [ ] `tactical-input` utility is defined.
- [ ] `tactical-focus` utility is defined.
