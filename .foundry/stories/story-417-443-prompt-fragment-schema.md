# Story: Define Prompt Fragment Schema

## Description
This story focuses on defining the standard schema and format for prompt fragments. It involves creating a structured definition (e.g., JSON schema or TypeScript interface) that represents a prompt fragment, allowing it to specify its role, context, tech stack rules, and precedence. It also includes creating initial standard fragments as a baseline.

## Scope
- Design the TypeScript interfaces/types for prompt fragments.
- Implement validation logic to ensure fragments adhere to the schema.
- Create initial foundational fragments (e.g., Generic Coder Role, React/Tailwind Tech Stack, TypeScript specific rules).
