# Story: Multi-Box Attribute Filters

## Context
Following the implementation of the global text search, we need to extend the search engine with attribute-based filtering to allow for more granular searches across all boxes.

## Objectives
- Implement UI controls for selecting attribute filters.
- Extend the search engine to filter Pokémon based on Nature, Ability, Gender, and Held Item.
- Ensure filters can be combined with the text search.
