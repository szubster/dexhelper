# Rematch Dashboard Layout and Routing

## Overview
Implement the base layout and routing for the Rematch Dashboard view component. This story covers the structural UI, ensuring it adheres to the tactical design system and is properly integrated into the application's navigation.

## Objectives
- Create the `RematchDashboard` view component.
- Set up routing to access the Rematch Dashboard.
- Ensure the structural layout adheres to ADR 008 (tactical hardware/snooping style, sharp edges, monospaced fonts).
- Use base tactical primitives (e.g., `tactical-panel`, `tactical-text`) from `src/index.css`.

## Acceptance Criteria
- [ ] Implement Rematch Dashboard structural layout.
- [ ] Set up application routing for the new view.
- [ ] Adhere to tactical design system constraints.
