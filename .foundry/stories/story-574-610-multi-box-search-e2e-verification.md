# Story: Multi-Box Search E2E Verification

## Context
To ensure the Multi-Box Search Engine works flawlessly, we need to implement end-to-end (E2E) verification covering both text search and attribute filtering capabilities across multiple boxes.

## Objectives
- Write and execute E2E tests for the global text search functionality (Nickname, Species Name, OT Name).
- Write and execute E2E tests for the attribute filtering (Nature, Ability, Gender, Held Item).
- Ensure complex combinations of search and filtering work correctly.
