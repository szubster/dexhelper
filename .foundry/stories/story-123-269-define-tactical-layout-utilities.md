# Story: Define Tactical Layout Utilities

## Objective
Implement custom layout utilities (`tactical-panel`, `tactical-card`) in `src/index.css` using Tailwind v4's `@utility` directive, in accordance with ADR 024.

## Scope
1. Define the `@utility tactical-panel` primitive in `src/index.css` implementing the dashed border, sharp corners, and retro aesthetics.
2. Define the `@utility tactical-card` primitive in `src/index.css` for layered components.
3. Ensure proper inheritance of variants.

## Acceptance Criteria
- [ ] `tactical-panel` utility is defined and tested.
- [ ] `tactical-card` utility is defined and tested.
