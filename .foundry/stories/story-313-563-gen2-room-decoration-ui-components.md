# Story: Gen 2 Room Decoration UI Components

## Overview
Implement the presentation components for the Gen 2 Room Decoration Viewer. This involves creating the categorized layout and visual highlights for Mystery Gift exclusives, adhering to the Tactical Hardware aesthetic.

## Requirements
- Create a dashboard or panel component to display unlocked room decorations.
- Display decorations in distinct categories: Beds, Plants, Posters, Consoles, Ornaments, Dolls.
- Use visual indicators (e.g., a specific tactical badge or border style) to highlight Mystery Gift exclusive decorations.
- Ensure the UI adheres to the Tactical Hardware styling constraints (ADR-008).
