# Epic Planner Learning: E2E Verification Rule for Epics

When generating Epics from a PRD, the requirement to "enforce a process where every EPIC generates a final STORY dedicated exclusively to Integration and E2E Verification" must be explicitly added to the Acceptance Criteria of *every* generated Epic.

Do not create a single standalone Epic for E2E testing, as this violates the mandate that *every* Epic must generate its own E2E verification Story.
