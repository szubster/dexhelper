# Journal Entry: $(date -u +"%Y-%m-%d %H:%M:%S")

When migrating components into `@dexhelper/ui`, I encountered a circular dependency issue. `TacticalSelect.tsx` incorrectly imported other UI components using the package's alias (`import { ... } from '@dexhelper/ui';`) instead of relative imports. This created a cycle (`TacticalSelect.tsx -> index.ts -> components/index.ts -> TacticalSelect.tsx`).

Always ensure that internal files within a package use relative imports (`./CornerCrosshairs`, etc.) to reference sibling components, rather than using the package's public export alias.
