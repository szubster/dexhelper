## Action
Researched WASM emulator options (mGBA vs binjgb) for DexHelper's web-based integration using GitHub APIs to pull README details for both projects.

## Findings
`binjgb` is highly performant and lightweight, running natively in the browser via WebAssembly with simple Javascript bindings for save state extraction. However, it only supports Game Boy and Game Boy Color. Since DexHelper actively supports Gen 3 (GBA) save parsing, `mGBA` is the superior option. `mGBA` supports GB, GBC, and GBA (Gen 1-3) and can be compiled to WASM, offering a unified engine for our entire feature set.
