# Architect Journal: Stringent Checkbox Parsing Rules

## Lesson Learned
When enforcing strict markdown checkbox parsing rules (`- [ ] ` vs `- [x] `) in the Orchestrator, simple regex approaches are prone to failure across varied AST implementations or formatting artifacts. The repeated failure of `task-726-727` suggests that standard library regex bindings may not correctly handle the leading whitespace or markdown list bounds within Gray Matter's content body.

Future parsing rules must utilize an explicit AST parser (like unified/remark) to traverse the syntax tree directly rather than relying on brittle raw text matching.
