## Target Tasks
`task-407-677-e2e-base-location-parsing-retry`
`task-407-678-e2e-mixed-records-rematch-retry`

## Details
During QA verification of the Gen 3 Secret Base and Mixed Record E2E tests, I observed that the tests in `tests/e2e/dashboard/gen3_secret_base.spec.ts` use `page.evaluate()` to manipulate the internal global state (`window.__store()`). This explicitly violates the Playwright E2E Testing Architecture rule, which requires tests to verify actual functionality by simulating real user interactions and asserting against rendered UI components on valid application routes.

## Action Taken
Both upstream implementation tasks have been marked as `FAILED` to trigger a transient rejection and allow the coder to update the E2E tests to rely on proper user interactions.
