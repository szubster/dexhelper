# Implement Gen 3 Pokéblock Blending Math Formulas

## Context
When berries are blended in Gen 3, the resulting Pokéblock's flavors and feel are calculated using specific formulas involving the base flavors and feel of the input berries.

## Requirements
- Implement pure functions that take an array of Berry profiles (flavor and feel base stats).
- Calculate the resulting Pokéblock's Spicy, Dry, Sweet, Bitter, and Sour values.
- Calculate the resulting Pokéblock's Feel value based on the Gen 3 formula.
- Write unit tests covering various blending scenarios.
