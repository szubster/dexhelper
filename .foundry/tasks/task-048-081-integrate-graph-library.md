# Integrate Selected Graph Library into DAG Dashboard

## Overview
Implement the graph rendering library chosen by the Architect into the DAG Dashboard component. This involves translating our DAG data format into a format that the library can consume and render effectively.

## Constraints
- The UI MUST adhere to a strict 'tactical hardware/snooping' aesthetic (sharp edges `rounded-none`, dashed borders `border-dashed`, monospaced telemetry fonts). Avoid generic web UI patterns like 'glassmorphism', soft drop shadows, or rounded corners.
- Refer to the ADR generated by the previous task for library-specific integration guidelines.

## Requirements
- Integrate the chosen graph library.
- Construct the interactive visualization of Foundry nodes using the chosen library.
- Ensure nodes and edges are styled appropriately.
- Ensure the graph is responsive and fits the dashboard layout.

## Acceptance Criteria
- [x] Integrate the chosen library into the DAG Dashboard component.
- [x] Render the DAG nodes and dependencies correctly.
- [x] Implement initial styling aligning with the tactical UI requirements.
- [x] Ensure basic interaction (e.g., panning/zooming if supported by the library) works correctly.
