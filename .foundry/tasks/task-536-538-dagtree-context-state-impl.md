# Implement DagTree Context and State Layer

## Objective
Create the React Context and state management layer to handle the expanded/collapsed state of the DagTree UI component.

## Scope
1. Implement a React Context provider for the DagTree.
2. Manage the state of which tree nodes are expanded or collapsed.
3. Expose functions to toggle individual nodes.
4. Expose functions to "Expand All" and "Collapse All" nodes.

## Acceptance Criteria
- [ ] Implement the DagTree Context provider.
- [ ] Implement state management for expanded/collapsed nodes.
- [ ] Implement functions to toggle, expand all, and collapse all nodes.
- [ ] Write unit tests for the context and state logic.
