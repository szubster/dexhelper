# Idea: Ruby/Sapphire Battle Tower Dashboard Support

## Description
Currently, the Gen 3 Battle Frontier Dashboard only extracts and displays data for Pokémon Emerald, as the full Frontier is exclusive to that version. However, Ruby and Sapphire feature the Battle Tower. Based on pending research (`research-078-150-rs-battle-tower-data`), we should update the parsing engine and the UI to support extracting and displaying Battle Tower win streaks for Ruby and Sapphire save files.
