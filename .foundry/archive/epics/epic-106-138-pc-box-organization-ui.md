# Epic: PC Box Organization UI

## Objective
Provide an intelligent, side-by-side guided sorting tool interface. The UI will display the current save state's PC boxes next to the proposed optimal layout and provide an interactive step-by-step "move plan" checklist for the user to execute manually.

## Features
1. **Dual-Pane View:** A UI displaying the current save state's PC boxes next to the proposed optimal layout.
2. **Strategy Selection:** A UI control allowing users to choose the desired sorting algorithm (e.g., National Dex order, Type, Level).
3. **Interactive Checklist:** A step-by-step checklist of operations (generated by the Move Planner) that updates as the user clicks through them.
4. **Adherence to Tactical Hardware Aesthetic:** Sharp edges (`rounded-none`), dashed borders (`border-dashed`), and monospaced telemetry fonts (`font-mono`).
