# Wire up DAG Dashboard UI to parsing layer data

## Overview
As the final step of the DAG Dashboard UI implementation, this story wires up the previously built interactive React Flow graph to consume the actual structured JSON DAG data generated by the data parsing layer (implemented in Epic 028).

## Requirements
- Fetch or receive the JSON graph structure provided by the data layer (from `.foundry` parsing logic).
- Transform the parsed data (nodes, edges, frontmatter fields) into the format expected by the React Flow graph components.
- Ensure dynamic updates if the underlying data changes, or handle the initial load correctly.

## Acceptance Criteria
- [x] Connect the UI components to the data layer source.
- [x] Verify that real `.foundry` nodes and their dependencies are correctly rendered in the graph.
- [x] Ensure filtering and highlighting still work with the real data.
