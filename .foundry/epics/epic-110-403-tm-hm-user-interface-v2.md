# TM/HM Inventory & Compatibility UI V2

## Overview
This Epic focuses on the User Interface (Presentation Layer) to provide visual components for interacting with TM/HM inventory and compatibility data.

## Requirements
- **Inventory Dashboard**: A visual grid displaying owned TMs/HMs and their quantities.
- **Compatibility Matrix**: A detailed view when a TM is selected, showing all compatible owned Pokémon.
- **Strategic Overlay**: Badges or indicators on compatible Pokémon showing if they lack a move of that TM's type.
- **Acquisition Tracker**: A list of unowned, uncollected TMs with their in-game locations.
