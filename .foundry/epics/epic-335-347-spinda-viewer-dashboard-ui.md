# Gen 3 Spinda Viewer Dashboard UI

## Description
This Epic ties the extraction and rendering engines together into a cohesive visual dashboard. Users will be able to upload their Gen 3 save file and view a gallery of all their uniquely patterned Spindas.

## Acceptance Criteria
- [ ] Create a dashboard gallery view to display the rendered Spinda sprites.
- [ ] Integrate the PID extraction logic with the Spinda Pattern Rendering Engine within the dashboard.
- [ ] Implement UI state handling for loading and parsing the save file, and displaying empty states if no Spindas are found.
