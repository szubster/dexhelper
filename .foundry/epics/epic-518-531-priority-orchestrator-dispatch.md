# Epic: Implement Priority-Based Dispatch in Orchestrator

## Context
Following the schema update, the orchestrator needs to leverage the new `priority` field to dispatch nodes intelligently.

## Functional Requirements
- Update `ReadyNodeItem` in `.github/scripts/foundry-orchestrator.ts` to include an optional `priority` field.
- Update the sorting logic to order by `priority` (descending) first, then `critical_weight` (descending), and finally `created_at`.
- Ensure downstream nodes generated by Epics/Stories/Tasks inherit this priority if set (this may require instructions in schema docs for generative personas).
