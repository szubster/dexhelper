# Epic: Wild Item Data Engine

## Context
This epic provides the foundational backend data logic for the Wild Held Item Hunting Assistant. It focuses on aggregating wild encounter data (routes and rates) and holding item probabilities across Gen 2 and Gen 3.

## Epic Requirements
- Parse and aggregate Pokemon encounter locations and rates for Gen 2 and Gen 3 games.
- Query and provide wild held item drop rates for specific Pokemon.
- Expose this data for UI consumption, enabling users to see the best routes for hunting a target item.
