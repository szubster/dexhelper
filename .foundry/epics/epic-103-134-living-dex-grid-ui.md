# Epic: Living Dex Numerical Grid & Box Overlay UI

## Context
This epic covers the visual representation of the Living Dex. We need a grid view that shows exactly where Pokémon reside in the PC boxes, and visualizes ghosts.

## Acceptance Criteria
- [ ] Implement a numerical grid view of all Pokémon in the Pokédex.
- [ ] Overlay the current PC box and Party state onto the grid.
- [ ] Visually highlight "ghosts" (missing slots).
- [ ] Adhere to tactical hardware/snooping aesthetic (ADR 008).
