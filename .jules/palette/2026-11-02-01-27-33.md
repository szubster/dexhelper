# Palette Journal Entry - Permanent Failures E2E Selector Resilience

## Date
2026-11-02

## Micro-UX / Accessibility Improvement
Fixed ancestor node locator in `tests/e2e/dashboard/permanent_failures.spec.ts` to reliably target closest card container.

## Key Learnings
- **Playwright Locator Ancestor Traversal**: When multiple nested container elements share Tailwind utility classes such as `border-dashed` (e.g. Kanban columns vs individual task cards inside columns), generic filtering like `page.locator('div.border-dashed').filter({ hasText: '...' }).first()` can resolve to the ancestor column container rather than the card element itself.
- Targeting the closest container using `page.getByText(...).locator('xpath=ancestor::div[contains(@class, "border-dashed")][1]')` resolves directly to the card element and prevents false-negative class assertion failures in Playwright E2E suites.
