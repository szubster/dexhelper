# Palette Journal Entry - DAG Tree Tactical Buttons & Telemetry Brackets A11y

## Date
2026-11-04

## Micro-UX / Accessibility Improvement
- Replaced raw `<button>` elements in `src/components/dag/DagTree.tsx` for "Expand All" and "Collapse All" with `<TacticalButton>` from `@dexhelper/ui`, adopting standard design system styles, crosshairs, and focus states.
- Wrapped decorative telemetry brackets (`[` and `]`) in `src/components/dag/DagTreeItem.tsx` around the node status with `<span aria-hidden="true">`.

## Key Learnings
- **Screen Reader Noise Reduction in DAG Tree**: Status badges in tree items display status strings like `[COMPLETED]` or `[ACTIVE]`. Wrapping decorative ASCII bracket characters in `<span aria-hidden="true">` stops assistive technology from announcing redundant "left bracket" and "right bracket" on every tree node traversal.
- **Consistent Interactive Controls**: Using `<TacticalButton>` from `@dexhelper/ui` across tree navigation controls aligns button styling with ADR 024 tactical primitives and ensures consistent `:focus-visible` styling (`tactical-focus`).
