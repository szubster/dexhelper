# Sculptor Refactoring - Magic Numbers in Save Parsers

## Critical Learnings
* **Inline magic numbers obfuscate data structures:** Using inline magic integers for array capacities (like `20`, `50`, `26`) and string parsing flags limits AI comprehension.
* **Top-level constants provide semantic mapping:** Extracting magic numbers to top-level constants (`MAX_ITEMS_POCKET_CAPACITY`, `TM_HM_COUNT`, `HIDDEN_ITEM_FLAGS_SIZE`) immediately clarifies their purpose and array bounds, especially important for parsing Gen 2 and Gen 3 Pokemon saves.
* **Refactoring Strategy:** Using custom Node (`.cjs`) scripts allows for precise, programmatic substitutions without truncation risks associated with bash `sed` commands on larger TS files.
* **Cleanup:** Always delete temporary scratchpad scripts before requesting code review to maintain a clean repository.
