# gen1Strategy Test Suite Consolidation

## Learnings
- **Parallel Test Suites with Divergent Mocking**: Two separate test files existed covering `gen1Strategy`: `src/engine/assistant/strategies/gen1Strategy.test.ts` and `src/engine/assistant/__tests__/gen1Strategy.test.ts`. The former heavily mocked dependencies (`resolveOutdoorMapId`, `getDistanceToMap`, `getUnobtainableReason`), while the latter used realistic domain data structures (`mockLocations`, `makeSaveData`) verifying genuine integration behavior across resolution, distance checks, unobtainable reason evaluation, and box warnings.
- **Duplicate Removal & Directory Hygiene**: In accordance with the repository convention placing engine assistant test suites inside `src/engine/assistant/__tests__/`, the redundant co-located test `src/engine/assistant/strategies/gen1Strategy.test.ts` was deleted, consolidating coverage into `src/engine/assistant/__tests__/gen1Strategy.test.ts` without loss of test functionality or regression in bundle/E2E behavior.
