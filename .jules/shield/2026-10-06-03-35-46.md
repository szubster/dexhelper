# Shield Journal Entry - Dependency Security Audit & Overrides

**Vulnerabilities Addressed:**
1. `source-map-js`: High severity event-loop denial of service (GHSA-68fv-2mgg-jv7q) resolved by upgrading to `^1.2.2`.
2. `seroval`: High severity memory exhaustion via unchecked TypedArray length in JSON deserialization (GHSA-jp82-f5mq-hwhp) resolved by upgrading to `^1.6.3`.
3. `smol-toml`: Moderate severity quadratic-time parse DoS (GHSA-r4xh-jqrq-34v2) resolved by upgrading to `^1.9.0`.
4. `postcss-selector-parser`: Moderate severity CPU exhaustion in flat selector parsing (GHSA-rj75-hqrm-r3gf) resolved by upgrading to `^7.1.6`.

**Action Taken:**
Added package overrides in `pnpm-workspace.yaml` under the `overrides:` block for `source-map-js`, `seroval`, `smol-toml`, and `postcss-selector-parser`.

**Key Learnings:**
- `pnpm` workspace overrides specified in `pnpm-workspace.yaml` allow forcing subdependency updates across all packages in a monorepo without waiting for upstream transitive dependencies to publish patch releases.
- Always verify that overridden version ranges use compatible semver limits (e.g. `^1.2.2`) so non-breaking patch/minor fixes are applied without causing runtime breakage.
