# Shield Security Journal - Dependency Security Audit Fixes

**Date:** 2026-11-07

## Summary of Action Taken
Performed a `pnpm audit` security audit and patched multiple vulnerable transitive dependencies using `overrides` in `pnpm-workspace.yaml`:
- **`zod`**: Overridden to `>=4.6.6` to resolve high-severity memory exhaustion during oversized collection validation (GHSA-mrhx-c7xc-m3w5).
- **`postcss-selector-parser`**: Overridden to `>=6.1.5` to resolve moderate CPU exhaustion / quadratic complexity parsing vulnerability (GHSA-rj75-hqrm-r3gf).
- **`glob`**: Overridden to `>=14.0.2` to resolve moderate AbortSignal cancellation bypass post-timeout filesystem traversal (GHSA-3g3m-2fjr-6pw4).
- **`minimatch`**: Overridden to `>=11.0.1` to resolve moderate denial of service via globparts amplification (GHSA-g3hv-75wg-m249).

## Key Learnings & Patterns
- Managing transitive vulnerability patches across pnpm workspaces is cleanly handled via the root `overrides` field in `pnpm-workspace.yaml`.
- Semver ranges should preserve compatibility while ensuring vulnerable ranges are superseded by patched versions.
