## 2026-10-04 - [Accepted] - 🖼️ Canvas: Bold FilterBadge & ClearFiltersBadge Hardware Redesign
**What:** Redesigned `FilterBadge` and `ClearFiltersBadge` from basic text badges into cased tactical hardware filter chips. Added 4-corner crosshair accents (`CornerCrosshairs`), dynamic active status LED dot (`TacticalLed`), left border status accent bar, micro telemetry code tags (`[SYS.FLT]`, `[SYS.ALL]`), CVA color variant support (`cyan`, `emerald`, `amber`, `red`, `purple`, `blue`), subtle LCD grid texture background (`LcdGrid`), and interactive hover scanline highlights (`ScanlineOverlay`) while maintaining full backwards compatibility.
**Outcome:** Merged (Optimistic execution)
**Why:** Filter buttons in search and filter arrays lacked hardware structure and tactile depth. The redesign elevates filter chips into cased micro telemetry modules adhering to the tactical hardware/snooping aesthetic (ADR 008), improving visual hierarchy and active filter feedback across telemetry dashboards.
**Pattern:** Filter chips and selector toggles should feature left accent status bars, status LED dots, and corner hardware accents to signal active filter states clearly.
