## 2026-11-08 - [Accepted] - 🖼️ Canvas: Bold TacticalIconButton Hardware Redesign
**What:** Redesigned `TacticalIconButton` from a plain icon button into an encapsulated micro tactical hardware telemetry trigger module. Added CVA variants (`default`, `primary`, `danger`, `secondary`, `amber`, `emerald`, `purple`), size variants (`sm`, `md`, `lg`), four-corner crosshair hardware accents (`CornerCrosshairs`), active LED indicator dot with pulse animation, interactive hover scanline overlay (`ScanlineOverlay`), and full backward compatibility.
**Outcome:** Merged (Optimistic execution)
**Why:** Icon-only action buttons across AssistantPanel, LocationSuggestions, PokerusSpreadPlanner, TacticalInput, RngTidSidDisplay, and PokemonDetails lacked tactile casing, physical depth, and consistent hardware status feedback. The redesign encapsulates icon triggers inside a sharp tactical hardware enclosure adhering strictly to ADR 008.
**Pattern:** Micro icon-only action triggers and toggles should feature cased dashed boundaries with corner crosshair accents, active LED status indicators, and subtle scanline hover overlays to signal interactive hardware controls.
