## 2026-11-07 - [Rejected] - 🖼️ Canvas: Bold TacticalCheckbox Hardware Redesign
**What:** Proposed transforming `TacticalCheckbox` into an encapsulated tactical hardware module with CVA theme variants, active LED status indicators, corner crosshairs, telemetry code tags, and a custom dashed checkbox element.
**Outcome:** Rejected → journaled
**Why:** Transforming basic inline checkboxes into padded card modules (`p-2.5`) caused layout regressions across compact UI contexts (toolbars, map layer panels, table filters) and hid the native input with `sr-only`, breaking standard browser click and visibility assertions. Additionally, the expanded CSS bundle exceeded BundleMon thresholds.
**Pattern:** Compact form elements (like checkboxes and inline toggles) should maintain their native inline footprint and visible native input characteristics rather than expanding into full padded card modules, preserving layout compatibility and standard accessibility/actionability semantics.
