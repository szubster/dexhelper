## 2026-11-07 - [Accepted] - 🖼️ Canvas: Bold TacticalCheckbox Hardware Redesign
**What:** Redesigned `TacticalCheckbox` from a plain native checkbox input into an encapsulated tactical hardware toggle module. Added CVA theme variants (`default`, `emerald`, `amber`, `red`, `blue`, `purple`), active LED status indicator dot with status glow, four-corner crosshair accents (`CornerCrosshairs`), subtle hover scanline highlights (`ScanlineOverlay`), sublabel telemetry text, codeTag badge slot, and a custom dashed tactile check indicator box with an animated SVG checkmark while preserving 100% backward compatibility for input props, standard refs, and standalone use cases.
**Outcome:** Merged (Optimistic execution)
**Why:** Checkboxes across map layer controls and checklist filters were visually plain standard browser inputs with an accent color. The redesign encapsulates toggle inputs inside a rugged tactical hardware module adhering strictly to ADR 008, establishing consistent hardware hierarchy and feedback across telemetry settings and filter panels.
**Pattern:** Toggle and checkbox components should feature cased hardware boundaries, corner crosshairs, active status LEDs, and telemetry tags to elevate tactile interactive feedback across settings and control screens.
