The Scribe persona's private memory is strictly `.jules/scribe.md` and must be used solely to log long-term lessons, architectural constraints, and recurring failures, not as an execution logbook to record completed tasks. Generation 3 save files use a double-buffered flash memory system consisting of SaveBlock A (0x0000 - 0xDFFF) and SaveBlock B (0xE000 - 0x1BFFF), which are divided into 14 4KB Sections identified by a 32-bit signature (0x08012025) at offset 0xFF8.
