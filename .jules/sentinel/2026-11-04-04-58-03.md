**Target Files:**
- `src/engine/mapGraph/gen1Graph.ts`
- `src/engine/mapGraph/gen2Graph.ts`
- `src/engine/mapGraph/gen3Graph.ts`

**Coverage Gap:**
- The generation-specific graph wrappers (`gen1Graph.ts`, `gen2Graph.ts`, and `gen3Graph.ts`) provide generation-preset distance calculation and outdoor map resolution for the Assistant recommendation engine.
- Prior to this session, while `src/engine/mapGraph/index.ts` was tested with explicit generation numbers passed to `getDistanceToMap`, the exported functions in `gen1Graph.ts`, `gen2Graph.ts`, and `gen3Graph.ts` had 0% test coverage.

**Actions & Learnings:**
- Created comprehensive unit tests in `src/engine/mapGraph/generationGraphs.test.ts` to verify:
  1. `gen1Graph.getDistanceToMap` delegates to unified `getDistanceToMap` with default generation 1 (including fallback to Saffron City for unknown maps).
  2. `gen1Graph.resolveOutdoorMapId` correctly traces indoor maps to outdoor parents.
  3. `gen2Graph.getDistanceToMap` delegates with default generation 2 (including fallback to Goldenrod City for unknown maps).
  4. `gen2Graph.getGen2MapName` decodes composite map group/ID bitshifted identifiers.
  5. `gen2Graph.resolveOutdoorMapId` resolves outdoor parent maps.
  6. `gen3Graph.getDistanceToMap` delegates with default generation 3 (including fallback to Littleroot Town for unknown maps).
  7. `gen3Graph.resolveOutdoorMapId` resolves outdoor parent maps.
- Verified 100% statement, branch, and function coverage across `gen1Graph.ts`, `gen2Graph.ts`, and `gen3Graph.ts`.
