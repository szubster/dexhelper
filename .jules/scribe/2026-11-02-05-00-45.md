# Scribe Journal - Gen 2 Bug Catching Contest Scoring Documentation

## Target Module
`src/engine/bugCatchingContest/gen2Scoring.ts`

## Motivation
The Generation 2 Bug-Catching Contest scoring engine implements the classic Game Boy Color judging formula from Pokémon Gold, Silver, and Crystal. While the code was functionally accurate, it lacked top-level `@module` documentation, comprehensive JSDoc explaining the architectural origins of the DV bitwise bonus (bit 1 of Defense, Attack, Special, and Speed yielding 16, 8, 4, 1 points respectively), and JSDoc tags (`@param`, `@returns`, `@example`) for `calculateGen2BugCatchingScore`.

## Actions Completed
- Added `@module bugCatchingContest/gen2Scoring` JSDoc detailing the contest's background and scoring system.
- Added JSDoc comments to `Gen2PokemonStats` interface and all its member fields (including the Gen 2 Special Attack/Special Defense DV sharing and the +29 shiny IV bonus).
- Added comprehensive JSDoc to `calculateGen2BugCatchingScore` documenting the 5 scoring components, `@param`, `@returns`, and `@example` code block.
- Added numbered inline comments explaining each scoring step (Max HP * 4, Stat pool, DV bit checks, HP / 8, Held Item).

## Key Learnings
- **Gen 2 Contest DV Bonus**: In Pokémon G/S/C, DV bonuses in the Bug-Catching Contest evaluate bit 1 (`Math.floor(iv / 2) % 2 !== 0`) of each 4-bit nibble. Defense grants 16 points (bit 4 of the bonus byte), Attack grants 8 (bit 3), Special grants 4 (bit 2), and Speed grants 1 (bit 0). Shininess in Gen 2 requires specific DVs that always satisfy these exact bits, guaranteeing the full 29 bonus points.
