# Bolt Optimization: Virtualize Pokedex Grid

- Replaced full DOM render of all Pokemon with a virtualized list using `@tanstack/react-virtual`
- Calculated columns based on `window.innerWidth` with a resize listener to map to `grid-cols` correctly and adaptively for responsive views.
- Used `useWindowVirtualizer` passing row slices of `finalPokemon` and rendering `<PokedexCard>`s.
- This optimization significantly reduces the number of React elements and DOM nodes created during searches and initial loads, dramatically improving Time-to-Interactive (TTI) and scroll performance on low-end devices.
