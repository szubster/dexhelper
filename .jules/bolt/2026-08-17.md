## Session Learnings\n- **Bundle Splitting Strategies**: By dynamically importing the generation strategies in `src/engine/assistant/strategies/index.ts`, the JS bundles are split by generation, reducing the initial payload downloaded by users. This addresses performance by ensuring code for other generations isn't loaded unnecessarily.\n- **Test Environment**: Ensuring playwright tests are run with `xvfb-run pnpm test:e2e tests/e2e/setup.spec.ts` provides a basic E2E check without stalling on full UI e2e tests when only underlying engine utilities are modified.
