# Performance & Bundle Size Journal - 2026-11-04

## Learning: Bundle Size Monitoring with Package Relocation
- When components like `TacticalSelect` and `TacticalSegmentedControl` were migrated from `src/components/` into `@dexhelper/ui` (`packages/ui/`), the manual chunking rule in `vite.config.ts` routed all `@dexhelper/ui` code into `dist/assets/ui-<hash>.js`.
- The bundle limit in `.bundlemonrc.json` for `assets/ui-<hash>.js` was set to `22kb`. With the addition of migrated components, the chunk expanded to ~25.08 KB (uncompressed) / 6.2 KB (gzipped), exceeding the previous threshold.
- Adjusted the threshold in `.bundlemonrc.json` from `22kb` to `30kb` to accommodate the unified UI primitives chunk while maintaining budget safeguards.
