# TacticalButton Refactoring in DagTree

- **What**: Replaced raw standard HTML `<button>` elements for "Expand All" and "Collapse All" in `src/components/dag/DagTree.tsx` with `TacticalButton` from `@dexhelper/ui` (`size="sm"`, `variant="secondary"`).
- **Why**: Reusing existing reusable design system primitives (`TacticalButton`) eliminates raw HTML button elements and boilerplate styling, ensuring consistent tactical theme styling and interactions (ADR 008 / ADR 024) across the DAG controls.
- **Key Learnings**:
  - `TacticalButton` variant="secondary" provides consistent `border-zinc-700 bg-zinc-900 text-zinc-400 hover:bg-zinc-800` matching the original button styles while standardizing focus rings, tactical tooltip titles, and accessibility attributes.
