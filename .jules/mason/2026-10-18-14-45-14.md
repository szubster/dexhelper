# TacticalCheckbox Extraction

- **What**: Extracted repeated standard `<input type="checkbox">` elements into a reusable `TacticalCheckbox` component.
- **Why**: Reduced code boilerplate in controls like `Gen3MapControlPanel.tsx` and standardized tactical theme styling for checkboxes (`rounded-none`, `border-dashed`, `tactical-focus`, custom check icon, and variants).
- **Key Learnings**:
  - `useId()` in React ensures each `TacticalCheckbox` generates a stable, unique ID for binding its `<label htmlFor="...">` element if a custom `id` is not passed.
  - Using `cva` (Class Variance Authority) allows clean variant handling (`primary`, `emerald`, `amber`, `red`) while preserving standard `HTMLInputElement` properties (`checked`, `onChange`, `disabled`).
