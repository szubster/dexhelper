## TacticalHeaderDivider Refactoring in Dashboard Components

- **What**: Refactored raw header section divider `div` elements (`flex items-center justify-between border-zinc-800 border-b border-dashed pb-2`) across multiple dashboard components (`Gen3TrainerCardDashboard.tsx`, `HallOfFameDashboard.tsx`, `ActiveCallersDashboard.tsx`, `ProgressionTimeline.tsx`, `BattleFrontierDashboard.tsx`) to use the reusable `<TacticalHeaderDivider>` component.
- **Why**: Reduced duplicated JSX markup and centralized header divider styling across dashboard panels to maintain tactical design language consistency.
- **Key Learnings**:
  - Utilizing `<TacticalHeaderDivider>` with custom `className` props allows seamlessly overriding border color (e.g. `border-zinc-700`) or layout direction (`flex-col items-start`) without breaking the default border-dashed bottom divider style.
