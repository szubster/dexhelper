# TacticalProgressBar Component Extraction

- **What**: Extracted repeated segmented stat/progress bar JSX patterns from `ContestConditionStats.tsx` and `ContestSheenDisplay.tsx` into a reusable `TacticalProgressBar` component (`src/components/TacticalProgressBar.tsx`).
- **Why**: Centralizes the tactical segmented progress bar UI structure, ensuring consistent accessibility attributes (`role="progressbar"`, `aria-valuenow`, `aria-valuemax`), segment calculations, and tactical borders while eliminating code duplication.
- **Key Learnings**:
  - `TacticalProgressBar` accepts flexible `valueDisplay` ReactNodes to handle both simple numeric values and complex formatted labels (such as `255 (MAX)`).
  - Combining `React.memo` and `React.forwardRef` ensures high performance during rapid state updates without losing standard HTML div props (`ref`, `className`, `data-testid`).
