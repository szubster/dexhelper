# TacticalSelect Refactoring in GameSwitcher

- **What**: Refactored `GameSwitcher.tsx` to replace a raw standard HTML `<select>` element with the reusable `TacticalSelect` component.
- **Why**: Reduced raw HTML input element usage and centralized select dropdown styling across concurrent game controls, improving visual consistency and tactical theme alignment (ADR 008 / ADR 024).
- **Key Learnings**:
  - `TacticalSelect` accepts custom `containerClassName` for controlling wrapper layout (e.g. `w-auto min-w-[120px]`) and `className` for internal select styling adjustments (e.g. removing default borders when embedded inside a bordered container).
  - Passing custom option styles (such as `bg-zinc-900`) allows the dropdown options to render cleanly across different browser user-agent themes.
