# TacticalButton Refactoring in NPCList

- **What**: Refactored `NPCList.tsx` to replace raw standard HTML `<button>` elements with `TacticalButton` from `@dexhelper/ui`, applying `variant="danger"` when an NPC is selected and `variant="default"` when unselected, with `className="w-full justify-start text-left"`.
- **Why**: Centralizes button styling and interactions to adhere to ADR 008/024 tactical design patterns while replacing manual inline CSS class toggles (`border-red-500 bg-red-500/20 text-red-500`) with standardized CVA design system variants (`danger`).
- **Key Learnings**:
  - `TacticalButton` defaults to center-aligned text layout (`justify-center`). When rendering full-width list items that need left-aligned text (such as selectable target entries), consumers should explicitly pass `justify-start text-left` in `className` to override the center alignment while preserving theme hover effects, borders, and tactical focus rings.
  - Using design system primitives rather than raw HTML elements prevents drift in hover/active styles and maintains consistent typography across panels.
