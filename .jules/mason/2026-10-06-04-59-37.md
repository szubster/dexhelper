# DecorationItemCard Extraction

- **What**: Extracted the inline `DecorationItemCard` component from `Gen2RoomDecorationDashboard.tsx` into a dedicated component in `src/components/gen2/DecorationItemCard.tsx`.
- **Why**: Standardizes item card rendering, integrates `TacticalBadge` from the project's design system for status badges (`ACTIVE` and `[MG]`), replaces raw `<div className="tactical-card">` with `<TacticalCard>`, and improves code modularity and testability.
- **Key Learnings**:
  - In `vitest-browser-react` component tests, `page` should be imported from `vitest/browser` (`import { page } from 'vitest/browser'`), not `vitest-browser-react`.
  - Replacing inline HTML span tags with design system primitives (`TacticalBadge`) ensures consistent tactical styling, animations, and hardware accent ticks across the application.
