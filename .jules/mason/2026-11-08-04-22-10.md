# TacticalButton Refactoring in DagFilterPanel

- **What**: Refactored `src/components/dag/DagFilterPanel.tsx` to replace raw standard HTML `<button>` elements for toggling permanent failures and heatmap overlay with `<TacticalButton>` from `@dexhelper/ui` (`size="sm"`, `hasCrosshairs={true}`, and dynamic `variant` based on toggle state).
- **Why**: Eliminates raw standard HTML button elements, removes duplicate inline styling and manual tailwind class compositions, and standardizes button interactions across DAG controls with tactical hardware design patterns (ADR 008 / ADR 024).
- **Key Learnings**:
  - Reusing `TacticalButton` variants (`danger` for permanent failures and `primary` for heatmap overlay) directly maps component active states to the design system's CVA palette instead of managing manual border/bg color strings.
  - Adding `hasCrosshairs={true}` gives toggle buttons hardware-inspired accent crosshairs that align with the tactical aesthetic across the application.
