# TacticalChip Extraction

- **What**: Extracted repeated inline chip/tag pattern (flex container with border-dashed, background opacity, uppercase text, and an optional close/remove button) into a reusable `<TacticalChip>` component.
- **Why**: Found repeated inline tag markup in `WildItemSelector.tsx` for rendering target item badges. Abstracting this into `TacticalChip` provides a modular component for removable tags and chips while adhering to ADR 008 tactical design language.
- **Key Learnings**:
  - `cva` is ideal for handling chip variants (`primary`, `zinc`), allowing easy customization of border, background, and text theme colors.
  - Omit native title attributes or handle them cleanly with `aria-label` / `title` on the remove button so Playwright tests using `page.getByTitle(...)` continue to function seamlessly.
