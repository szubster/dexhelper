# Journal - Infra Tooling Improvement: Vite OXC Migration

## Observations
- The Vite configuration was using the default Babel-based `@vitejs/plugin-react`.
- Babel parsing during build and development server HMR is slower than modern rust-based alternatives.
- While `@vitejs/plugin-react-swc` was considered, it is older and I was explicitly instructed to use the modern `oxc-transform-react` via `unplugin-oxc`.

## Decisions & Learnings
- **Action:** Migrated Vite's React plugin from `@vitejs/plugin-react` to `unplugin-oxc/vite`.
- **Reason:** `oxc` is an extremely fast rust-based parser and transformer, providing superior build speeds and HMR performance over Babel without modifying application logic.
- **Gotchas:**
  - Ensure the plugin is imported correctly from `unplugin-oxc/vite` instead of standard vite plugins.
- **Outcome:** Build tests (`pnpm build`, `pnpm lint`, and `pnpm test`) all pass successfully and rapidly.
  - The \`oxc-transform-react\` output code might have a different size profile than babel code. \`assets/gen2-<hash>.js\` grew from ~19KB to just above 20KB limit set by BundleMon, resulting in CI failures. Fixed by bumping its BundleMon limit up to 25KB.
