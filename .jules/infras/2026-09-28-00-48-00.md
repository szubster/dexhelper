## Critical Learnings
- **Dependency Cruiser TS7 Incompatibility**: `dependency-cruiser` (v18) cannot transpile TypeScript when the repository uses TypeScript 7+ (`typescript: ~7.0.2`), outputting `missing-typescript-transpiler` and scanning 0 modules. Removing `dependency-cruiser` in favor of Oxlint (`.oxlintrc.json` import boundaries) and `dpdm` (`pnpm lint:circular`) eliminates dead tooling and cleans up `pnpm lint`.
- **Lefthook Oxlint Alignment**: `lefthook.yml` must explicitly pass `-c .oxlintrc.json` to `oxlint` so local pre-commit hooks enforce the same architectural import boundaries configured for CI.
