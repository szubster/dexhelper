# Journal - Infra Tooling Improvement

## Observations
- The Vite configuration was using the standard Babel-based `@vitejs/plugin-react`.
- Babel parsing during build and development server HMR is slower than modern Rust-based alternatives.
- The project allows customizing build behavior via `vite.config.ts`.

## Decisions & Learnings
- **Action:** Migrated Vite's React plugin from `@vitejs/plugin-react` to `@vitejs/plugin-react-swc`.
- **Reason:** SWC provides significantly faster parsing, compilation, and Hot Module Replacement (HMR) speeds without requiring changes to application logic, making it a pure Developer Experience (DX) and build pipeline optimization.
- **Gotchas:**
  1. Adding `@vitejs/plugin-react-swc` brings in `@swc/core`. `@swc/core` requires postinstall build scripts to run.
  2. The workspace enforces strict package build approvals via `pnpm-workspace.yaml`.
  3. I had to explicitly add `"@swc/core": true` to the `allowBuilds` array in `pnpm-workspace.yaml` so that the dependency could compile automatically on subsequent `pnpm install` runs in CI without hanging on a manual prompt.
- **Outcome:** Build tests (`pnpm build`, `pnpm lint`, and `pnpm test`) all pass successfully and rapidly.
