# Nurse Joy Journal Entry

- **Issue:** Unsafe `as import('../../../db/schema').PokemonMetadata` type assertions on `m1` and `m2` in `src/features/shiny-breeding/components/ShinyBreedingManualSelector.tsx`.
- **Solution:** Typed `metadataMap` as `Map<number, PokemonMetadata>` using `new Map<number, PokemonMetadata>()` with `PokemonMetadata` imported from `../../../db/schema`. Retrieved `m1` and `m2` into local variables and used standard truthy narrowing (`if (store.parent1 && store.parent2 && m1 && m2)`), cleanly eliminating the unsafe `as` casts.
- **Learn:** Under TypeScript strict null checks (`@tsconfig/strictest`), `map.has(key)` does not narrow subsequent calls to `map.get(key)`. Storing the retrieved item in a variable (`const m1 = map.get(key)`) followed by a truthy check (`if (m1) ...`) safely narrows the type to non-null without needing `as` type assertions.
