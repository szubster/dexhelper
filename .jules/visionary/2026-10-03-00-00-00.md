## Critical Learnings & Strategic Insights
- **Rationale & Concept**: Scheduled background agents (such as `visionary`, `agile_coach`, `tpm`, `librarian`, `curator`) run on cron schedules to maintain the software factory. When environment or schema issues cause repeated failures, these agents continue executing on fixed schedules, wasting compute and API tokens. An automated circuit breaker state machine will detect consecutive failures, pause/throttle agent dispatches, and raise diagnostic alerts to protect factory resources.
- **Strategic Balance**: In the preceding session, IDEA-533 (`idea-533-gen3-daycare-iv-inheritance-calculator`) was proposed as a direct product feature for DexHelper. To strictly maintain the required 50/50 balance between product features and system improvements, this session pivots back to a high-value Foundry Orchestrator infrastructure capability.
