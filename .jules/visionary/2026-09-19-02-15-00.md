## Critical Learnings & Strategic Insights
- **Domain:** Main Project (DexHelper)
- **Proposed Idea:** Gen 3 Mirage Island Radar & PID Match Calculator (IDEA-526)
- **Rationale & Concept:**
  Mirage Island in Gen 3 (Ruby, Sapphire, Emerald) is one of the rarest events in Pokémon history (1 in 65,536 daily chance per Pokémon). Every day at midnight RTC, the game generates a 16-bit random number (`0x0814` offset in Section 1). The island appears on Route 130 if and only if the lower 16 bits of the Personality Value (PID) of any Pokémon in the player's current party match this random number.
  By parsing the save file, DexHelper can extract the active Mirage Island random value and scan all Pokémon across both active party and stored PC boxes to determine if an existing Pokémon in the player's save matches the value (or if they are close/which Pokémon to check with the Pacificlog Old Man).
