# Sweeper Journal Entry

## Summary
Successfully identified and removed several unused configurations and constants from the Generation 3 save data parsing module (`src/engine/saveParser/parsers/gen3.ts` and related files) using `pnpm knip`. These included constants like `TRAINER_FLAGS_START`, `GEN3_PARTY_SIZE_OFFSET_RSE`, and `PC_BOX_NAMES_OFFSET`.

## Critical Learnings
*   **Knip for Dead Code:** `knip` is a highly effective tool for identifying unreferenced exports and constants in this codebase.
*   **Safe Removals:** Deleting unused constants in parser files is typically very safe and unlikely to cause regressions, provided you double-check for dynamic usages or implicit requirements (like test files).
*   **Clean Working Directory:** Always ensure temporary files generated during analysis (like `knip-output.txt`) are deleted before requesting code review or submitting the PR to maintain a clean repository.
