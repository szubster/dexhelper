# Sweeper Session

## Actions
Deleted the completely unused directory `src/engine/saveParser/gen3/mixedRecords` which contained unused types and constants. Also deleted `src/engine/saveParser/utils/index.ts` and synced the `knip.json` configuration file to remove these paths from the ignore list.

## Learnings
* **Leftover knip config**: Similar to the previous `.github/scripts/schema.ts` finding, files like `src/engine/saveParser/gen3/trainerFlags/parser.ts` were present in the ignore list for `knip.json` but shouldn't have been. These instances should always be monitored.
* **Dead Code Trees**: Be aware that unused exports caught by `knip` can often just be an entire unreferenced tree of code (in this case `src/engine/saveParser/gen3/mixedRecords`), so instead of just deleting an export, evaluate if the entire file/directory is dead weight.
