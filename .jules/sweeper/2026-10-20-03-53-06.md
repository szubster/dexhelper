# Sweeper Session Learnings

## Unused Export & Dead Code Cleanup
When `pnpm knip` identifies unused files, verify using `grep` across `src/` and `tests/` that no relative imports or dynamic references exist. Dead files like barrel exports (`src/components/map/heatmap/index.ts`) or unreferenced type modules (`src/engine/saveParser/parsers/gen2/kurt/types.ts`) can be safely deleted to reduce clutter and improve build/lint performance.
