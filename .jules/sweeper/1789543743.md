# Sweeper Journal

## Dead Code Cleanup Strategy
When using `knip` to find and delete unused files, barrel files (`index.ts`) will often be flagged. Do not merely delete the barrel file and leave the underlying files intact, as that orphans them. Inspect the barrel file and ensure the specific implementation files it exports are also removed if they are genuinely unused.

## Strict Scope Constraint
When tasked with solving "ONE" piece of technical debt, ensure the deletions or modifications are isolated to a single logical domain or issue (e.g. only benchmark scripts, or only unused UI components). Avoid performing a scattershot cleanup of everything `knip` finds across the entire codebase in a single PR, as that violates the strict "ONE issue" boundary.
